# 网页配置联网搜索

第一版通过 Tavily Search 搜索资料、Tavily Extract 提取公开网页正文。模型 API 与搜索服务独立配置，不需要命令执行服务或浏览器自动化。

## 使用

1. 登录后进入“设置 → 联网搜索”，服务商选择 Tavily，输入自己申请的 API Key。
2. 勾选“启用联网搜索”；按需保留“允许读取网页正文”，保存配置。
3. 点击“测试联网连接”，页面显示耗时和结果数量；测试发送固定查询 `Tavily documentation`，可能消耗 Tavily 额度，每 10 秒最多一次。
4. 聊天中要求“搜索某个主题并附来源”或“读取这个公开网址并总结”。助手按需要调用工具，参数和结果展示在原有任务记录中，回答由模型生成。
5. 定时 AI 需要另行勾选“允许定时任务联网”。默认关闭，不因普通聊天启用联网而获得权限。

密钥仅保存在服务端数据库；网页只显示“已配置/未配置”。留空保存保留原密钥，填写新值替换；勾选清除并保存同时关闭联网。数据库含凭据，不能提交或放进助手授权工作目录。设置页有未保存提示、刷新/退出提示、错误重试及版本冲突保护。无需新增环境变量，保存后无需重启。

搜索词和目标网页 URL 会发送给 Tavily；网页提取由第三方服务完成。当前采用基础搜索/提取，没有自动升级搜索深度、自动重试、自动答案或跨任务缓存。工具提示不发送无关私密内容，但这不是通用数据防泄漏过滤器。

## 工具与预算

| 工具 | 输入 | 输出 |
| --- | --- | --- |
| `web_search` | `query`：非空、最多 500 字符；可选 `maxResults`：1–5，默认 5 | 标题、URL、摘要、可获得的原始发布时间、抓取时间与截断标记 |
| `web_fetch` | `url`：公开 HTTP(S) 网页，最多 2048 字符 | 可获得的标题、来源 URL、正文、抓取时间与截断标记 |

每任务最多 6 次联网工具调用（失败也计入）；每次网络请求最多 8 秒、响应体最多 1 MiB。搜索单条摘要最多 700 字符、标题最多 200 字符，总结果 JSON 超过预算时减少条目并标记截断；正文最多 6000 字符。统一受现有 2 分钟任务时限、8 轮模型循环和上下文预算约束。工具 JSON 不会因正文过长失去来源字段。

`fetchedAt` 为服务器本地时间 `YYYY-MM-DD HH:mm:ss`；搜索 `publishedAt` 是上游原始发布时间文本，可能为空，不冒充抓取时间。正文返回的 `url` 是 Tavily 报告的来源地址，不保证表示完整 HTTP 重定向链的最终地址。无搜索结果返回空列表；提取失败、认证失败、额度受限、超时、非法响应分别显示明确错误，不返回上游原始错误正文或凭据。

网页与搜索结果是参考数据，不能更改工具权限或替代授权。模型被要求引用实际返回的 URL，并区分摘要、正文及截断内容；实际引用准确性仍取决于模型，需要真实联合验证。前端沿用安全 Markdown 渲染。

## 配置和运行一致性

- 创建任务时绑定当时的联网配置和密钥；`tasks.web_snapshot` 只保存公开配置与版本，不包含密钥。
- 启用功能或放宽权限不会提升已创建任务的权限，新任务采用新配置。
- 每次工具准备和执行都校验当前总开关、正文/定时权限与密钥是否仍匹配。关闭、清除密钥或更换密钥后，旧任务不能继续使用已失效权限；仍可按原有任务流程结束或报错。
- 任何成功保存都会中止该用户正在进行的联网请求。保存失败或版本冲突不会中止请求。修改后的允许范围也会应用于后续调用。
- 用户取消、任务超时和服务关闭均中止本机网络请求，并拒绝迟到结果；第三方可能已处理的请求不承诺退款或撤销。
- 定时任务始终禁止写文件和执行命令；联网只是显式允许的只读资料获取。重启中断任务，不自动重放已调用工具。

## 网络访问边界

服务仅向固定的 `https://api.tavily.com/search` 和 `/extract` POST，请求禁止重定向；不存在用户可配置的搜索服务地址。模型提供的 URL 只作为数据交给 Tavily，不在 MlClaw 主机上解析或抓取。

输入和返回来源拒绝非 HTTP(S)、凭据、IP 地址、自定义端口、单标签和常见本地域名，去除片段。该校验不是本机任意 URL 抓取的 SSRF 防护实现；公开域名的 DNS 与重定向由 Tavily 处理。未来若增加本机抓取器，需另行实现 DNS、实际连接 IP 及逐跳重定向校验。

不支持登录网页、浏览器交互或保证所有网站可提取，不添加服务器代理配置。部署主机需要能够访问 Tavily。

## 使用限制

联网功能依赖有效的 Tavily 配置及模型工具调用能力；结果准确性和网页提取效果需要结合实际来源核对。接口说明：[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[Tavily Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract)。
