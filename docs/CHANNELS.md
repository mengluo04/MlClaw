# QQ 与微信机器人接入

当前支持每个平台一个机器人账号、已绑定本人的私聊文本。连接与消息送达取决于平台账号权限、额度和会话有效期。

## 使用前提

- 按 [本机使用说明](LOCAL_USAGE.md) 启动 MlClaw、登录并配置全局默认模型。
- 服务进程能访问平台 HTTPS / WSS 接口。连接由服务端发起，不要求公网回调地址。
- QQ 需要在 [QQ 开放平台](https://q.qq.com/) 创建机器人及取得私聊所需权限，不能用普通个人 QQ 登录代替。
- 微信使用腾讯 `@tencent-weixin/openclaw-weixin` 所采用的扫码连接机器人方式，不是企业微信或桌面微信自动化。
- 模型和受限工具继续使用 MlClaw，无需安装 OpenClaw、配置其网关或运行插件安装器。

## 连接 QQ

1. 展开网页“消息渠道 · QQ / 微信”。
2. 填写 `QQ AppID` 和 `QQ AppSecret`，点击“保存 QQ 配置”。
3. 点击账号的“连接渠道”，查看连接状态。
4. 点击“生成QQ绑定码”，用本人 QQ 向机器人私聊发送页面显示的完整 `/bind 绑定码`。
5. 页面显示已绑定的平台身份后，再发送问题。

AppSecret 不回显。同一 AppID 下省略密钥保留原凭据；更换 AppID 必须提供新密钥，且不继承旧身份、会话映射或投递记录。保存配置会停止该渠道及其运行任务，需要重新连接。平台可能要求在控制台配置测试成员或开通相应能力，以账号实际权限为准。

## 连接微信

1. 点击“微信扫码连接”，用微信扫描二维码并在手机确认。
2. 如手机显示数字，在网页“微信验证码”填写并提交。
3. 二维码最多 5 分钟有效，过期后重新生成。“关闭扫码会话”可取消待扫码流程。
4. 登录成功后点击“生成微信绑定码”，用本人微信向机器人发送完整 `/bind 绑定码`。
5. 页面显示已绑定身份后，再发送问题。

刷新网页可恢复当前服务进程内的扫码状态。服务重启会清除未完成扫码会话；已保存账号按启用状态重新连接。平台返回登录失效后停止轮询，需重新扫码。

同一机器人重新扫码保留已有身份绑定；更换使用者前先解除绑定。“移除渠道”删除本机凭据及绑定，不代表撤销微信平台授权，平台连接管理需要在微信端操作。已确认扫码会话的“关闭”只清除扫码记录，不会退出已连接账号。

## 身份、会话与工具

- 绑定码随机生成，仅生成时返回明文，数据库保存摘要，5 分钟过期；生成新码立即使旧码失效。每账号每分钟最多校验 10 次格式正确的绑定尝试。
- 一个渠道账号只绑定一个平台稳定身份，不依赖昵称。未绑定、身份不匹配和群聊不进入任务；微信机器人消息忽略。
- QQ 与微信按渠道账号、发送者隔离历史；全局助手配置、显式记忆和默认模型共享。
- 点击“刷新对话列表”查看渠道会话；投递记录的“打开对应会话”可查看任务和批准工具。
- `/stop` 只取消当前渠道私聊任务，不影响另一个渠道或网页独立会话。
- 全局仍只运行一个任务，忙碌时明确提示，不自动排队，需用户稍后重新发送。
- 工具批准仍在网页核对具体参数后完成；聊天里“同意”不能批准。任务总时限 120 秒，包含等待批准时间。
- 网页在渠道会话中新发消息的回复仅显示于网页，不自动额外投递到平台。

## 发送与恢复

重复入站消息不会创建第二个任务。发送失败或结果未知时不自动重发，请到原聊天核对；服务重启不会重跑旧消息。停止、解绑或移除渠道会取消该渠道的运行任务和未发送回复。

每账号最多保留 10000 条已接纳入站记录，达到上限后拒绝新消息并显示错误。当前没有归档清理界面；移除重建渠道会清除渠道记录并要求重新绑定，网页会话历史保留。

当前不支持群聊、多媒体、多账号和平台内工具批准。定时提醒与 AI 结果投递见 [定时任务说明](SCHEDULES.md)。渠道凭据保存于服务端数据库，数据库不能公开或放进助手授权工作目录。第三方来源见 [许可声明](THIRD_PARTY_NOTICES.md)。
