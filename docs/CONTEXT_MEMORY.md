# 会话摘要与记忆检索

当前支持：会话摘要、按问题选取显式记忆、查询已结束任务的工具证据。原始聊天和用户维护的记忆分别保存；没有自动记忆写入、向量检索或当前工具循环内的压缩。

## 网页使用

选择对话后，从右上角菜单进入“会话详情与规则”，展开“会话摘要与上下文”，可手动生成、继续生成、清除摘要或启用“本会话自动摘要”。自动开关默认关闭，保存立即生效于本会话的新任务。生成使用任务创建时的默认模型，可能增加费用。页面显示覆盖数量、剩余消息、截止消息 ID、模型、时间、有效性和长消息截断提示。

手动生成占用全局任务名额，可以取消；失败、中断或取消后可重新生成。它不创建用户/助手聊天消息，不调用工具。清除仅清除摘要，全部原始消息保留。关闭自动摘要不会删除已有摘要；要停止使用已有摘要请清除。

展开“记忆与历史检索”输入中文或英文关键词。记忆搜索最多返回 10 条，没有匹配显示空结果。历史任务默认查询当前会话，可显式选择“我的全部会话”；点击“查看历史证据”读取工具结果摘要，长记录可翻页。此查询不会重跑任务，也不继承历史批准。

## 摘要处理与限制

新聊天使用有效摘要和其后的原始消息，不重复注入已覆盖消息。剩余原始历史仍最多 40 条、24,000 字符，且受总上下文预算约束；关闭自动摘要时，超预算省略通过 `context.omitted` 事件提示。

开启自动摘要后，超过上述限制或总预算需要省略历史时，先摘要较早消息，保留最近最多 8 条且尽量不超过 12,000 字符的原文（至少保留最新一条）。手动生成则尽量覆盖全部剩余消息。单次任务最多读取 200 条待处理消息、最多 8 批模型请求，每批来源 JSON 最多 12,000 字符；每条消息的内容 JSON 超过 8,000 字符时省略中间内容并记录截断标记。摘要输出最多 4,000 字符，原文不变。

所有批次成功后才保存本次摘要；失败、取消或生成期间来源/设置变化不替换有效旧摘要。历史过长时可多次继续生成；自动处理后仍无法容纳剩余历史，会保留已经成功保存的摘要并提示继续手动生成，当前聊天任务失败。摘要不能保证无损，核实执行情况应查询原任务工具证据。

来源只包含聊天消息与有效旧摘要，不注入独立记忆、助手配置或工具结果。摘要被标为参考数据，没有授权效力。已覆盖消息的正文、角色或 ID 更新以及删除会使摘要失效；生成保存前还校验来源指纹和版本。失效摘要不再注入任务，重新生成从原始消息开始。没有新增消息编辑界面。

手动摘要是 `kind=summary` 的普通任务，自动摘要属于聊天任务准备阶段。共同遵守全局串行、幂等、120 秒总时限、取消和重启中断；重启不自动重跑。摘要请求用量与聊天用量累加，仅记录 Provider 实际上报值。摘要请求最多 8 次，与之后最多 8 轮工具循环分别计数，但共享任务总时限。

## 记忆与历史查询

长期记忆由用户维护，当前采用关键词匹配，不是向量或语义检索。删除记忆不会删除聊天正文中已经出现的相同内容。

记忆搜索位于“记忆与技能 → 长期记忆”；历史查询位于“运行记录”，默认全部会话，可切换到当前已打开的会话。查询已结束任务不会重新执行工具或继承过去的批准。长结果会明确标记截断。

摘要可能遗漏或误解信息，需要核对重要事实；原始消息始终保留，失败或取消不会覆盖有效旧摘要。
