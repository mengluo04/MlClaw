# 技能自动匹配与按需加载

当前技能为 Markdown 操作说明。用户通过网页管理技能，助手根据任务自主判断是否使用，无需每次手动选择。实现借鉴 [OpenClaw 的技能目录与按需读取机制](https://docs.openclaw.ai/concepts/system-prompt#skills)，另增加对技能正文和参考文档的关键词检索。没有安装完整 OpenClaw 运行时。

## 使用方式

进入“记忆与技能 → 技能管理”，点击“新增技能”进入编辑区，填写以下内容并保存：

- 技能名称：小写英文、数字和中划线，例如 `weekly-report`。
- 适用场景描述：说明处理什么问题、何时使用和不适用的场景。初始模型上下文会包含它。
- 匹配关键词：可选，逗号分隔，例如“周报，汇总成果，工作总结”。关键词是候选线索。
- 技能说明：Markdown 工作步骤、输入要求、输出格式与核查要求。
- 参考文档：可选的较详细说明。给文档命名，例如 `checklist.md`，并在技能说明中引用这个名称。

“启用并允许自动匹配”默认勾选，保存后供新任务发现。描述应具体，例如“根据工作记录整理周报，列出完成事项、风险和下周计划；不用于单次技术问答”。有未保存修改时，切换编辑、重新加载、刷新和退出会提示；保存发生版本冲突时保留草稿，重新加载前可自行复制内容。

“搜索技能候选”查询已保存且启用的技能，不调用模型；它可以帮助检查关键词是否能找到正文或参考文档。它不代表模型自动选择质量测试。

在聊天中直接提出任务，如“帮我汇总这周成果”。聊天中展开“执行过程”可查看实际读取的名称、版本、文档和时间。工具记录另保留查询与返回结果。加载说明不代表整个技能流程已经执行成功，应结合任务终态、结果和工具证据判断。

## 运行过程

1. 创建任务时固定当时已启用技能的内容、版本和访问版本。
2. 初始上下文注入名称、描述、关键词、ID、版本和选择规则，不注入正文或参考文档全文。目录过长会缩短描述/关键词，保留所有技能身份信息并标记 `shortened`。
3. 模型根据任务含义选择适用技能；没有适用技能时可正常回答。描述不足时调用 `search_skills` 查名称、描述、关键词、正文和参考文档，获得候选片段。
4. 选择后调用 `read_skill` 读取完整说明，再用 `read_skill_resource` 读取所需参考文档。文档名称必须来自该技能，且必须先读技能说明。
5. 模型依照已读取说明调用已有工具，网页显示实际加载记录。

候选片段进入上下文用于判断，不是完整操作说明；不能仅凭搜索命中就执行技能。当前没有单独的关键词自动执行器、向量数据库或额外分类模型。搜索使用 NFKC、大小写归一化和中文分词，最多 8 个词；完整查询匹配计 20 分，每个词匹配计 2 分，名称/描述/关键词部分乘 3，正文与参考文档乘 1。按总分排序，返回得分最高字段附近的片段。同义表达的判断依赖当前模型，可能误选或漏选。

普通网页、渠道和定时任务共用此流程。技能不会自动提升定时任务的只读权限，也不会打开联网；需要相应工具时仍受其原有配置限制。会话摘要生成不提供技能或任何工具。

## 修改、撤销与权限

编辑技能后，新任务使用新版本，已经创建的任务继续使用其固定版本。禁用或删除会立即阻止后续技能搜索和读取；禁用后重新启用也不会恢复旧任务的读取资格。新建或原先未启用的技能不会加入已经创建的任务。

已进入运行上下文的内容不能通过禁用倒退移除；如需立刻停止当前任务，应取消任务。禁用不清除历史任务、原始消息或已记录的工具结果。模型历史检索工具不会回放 `search_skills`、`read_skill`、`read_skill_resource` 的旧结果，避免借历史查询重新注入旧技能；管理页面的原任务工具记录仍可审阅。

技能只是工作方法，不授予文件、联网或命令权限，不替代用户批准。技能无法注册新工具或修改服务端授权策略。文件覆盖和命令执行继续执行现有授权检查。

## 容量

| 项目 | 首版上限 |
| --- | --- |
| 技能数 | 每用户 30 个，包括停用技能 |
| 名称 / 描述 | 64 / 300 字符 |
| 关键词 | 10 个，每个 30 字符 |
| 技能正文 | 8000 字符，JSON 序列化后最多 9000 字符 |
| 附属文档 | 每技能 5 份，每份 4000 字符，JSON 序列化后最多 6000 字符 |
| 技能总容量 | 单技能序列化后 32000 字符；保存时用户已有技能含元数据与待保存文档合计最多 160000 字符 |
| 初始目录 | 条目 JSON 最多 9000 字符，另外包含短包装字段和选择规则 |
| 搜索 | 查询 1–200 字符，最多 5 个候选，单片段 350 字符，结果 JSON 最多 6000 字符 |
| 任务读取 | 最多加载 3 个不同技能；搜索/读取合计最多 12 次 |
| 任务输出 | 技能相关输出累计最多 24000 字符，单次最多 12000 字符，另受任务总上下文预算限制 |

重复读取也计调用数和输出容量；只记录实际成功读取的技能和文档。搜索不会产生加载记录。技能工具复用现有取消、时限和最多 8 轮工具循环，达到限制后返回明确错误。

## 当前限制

本版不提供 `SKILL.md` 文件包导入、磁盘目录扫描、ClawHub 安装、脚本运行或依赖安装；附属文档是数据库文本，只接受文档名称，不把名称当成路径或 URL。可把外部技能中的适用描述和操作说明填入网页，但依赖的工具必须已由 MlClaw 实现并授权。
