# 本机使用说明

本机源码运行不需要 Docker，命令执行服务默认关闭。容器运行见 [部署说明](DEPLOYMENT.md)。

## 1. 启动与登录

要求 Node.js 24 LTS、npm 11。

1. 在项目根目录执行 `npm ci`。
2. 首次使用时，将根 [.env.example](../.env.example) 复制为 `apps/server/.env`，填写自己的 `ADMIN_PASSWORD`（12–256 字符）。已有环境文件不要覆盖。
3. 保留 `EXECUTOR_URL`、`EXECUTOR_TOKEN` 为空，执行 `npm run dev`。
4. 浏览器访问 `http://127.0.0.1:5173`，使用 `ADMIN_USERNAME`（默认 `admin`）和初始化密码登录。

初始化后可移除环境文件里的 `ADMIN_PASSWORD`；修改该变量不会重置已有管理员密码。

| 配置 | 默认值或用途 |
| --- | --- |
| `HOST`、`PORT` | API 默认监听 `127.0.0.1:3000` |
| `APP_ORIGIN` | `http://127.0.0.1:5173`，必须与浏览器访问来源一致 |
| `DATABASE_PATH` | `data/mlclaw.sqlite`，使用工作区启动脚本时位于 `apps/server/data/` |
| `WORKSPACE_PATH` | `workspace`，使用工作区启动脚本时位于 `apps/server/workspace/` |
| `ADMIN_USERNAME`、`ADMIN_PASSWORD` | 首次管理员初始化 |
| `EXECUTOR_URL`、`EXECUTOR_TOKEN` | 可选执行服务；当前留空 |
| `NODE_ENV` | 当前使用 `development`；生产模式要求 HTTPS 来源 |
| `LOG_LEVEL` | Pino 标准输出最低级别，可选 `info`、`warn`、`error`，默认 `info` |

相对路径以服务进程工作目录为基准。不要让授权工作目录包含应用配置或数据库；数据库含模型密钥和聊天内容，不应提交或公开。前端通过 Vite 代理请求 `/api`，更改后端端口时也需调整 `apps/web/vite.config.ts`。

## 2. 模型与对话

1. 进入“设置 → 模型服务”，点击“新增提供商”，填写提供商名称、兼容 Chat Completions 的服务地址及 API 密钥。地址包含 API 前缀（例如 `https://服务地址/v1`），不包含末尾 `/chat/completions`。非本机服务要求 HTTPS，回环服务可使用 HTTP。
2. 在“模型列表”中每行填写一个该服务实际支持的模型标识，点击“保存提供商”，关闭编辑抽屉后选择全局默认模型。最多 20 个提供商，每个提供商最多 50 个模型，列表不自动从服务端获取。
3. 按需点击“新增提供商”配置其他服务；同一提供商的多个模型共用地址和密钥，各提供商密钥独立。
4. 从“全局默认模型”中选择一个“提供商 / 模型”并点击“保存默认模型”。未指定默认时不能发送新任务；升级前已有单模型配置会自动成为默认。

所有对话后续发送、手动新任务重试均使用当前全局默认模型，无需逐个对话设置。运行中或等待授权的任务继续使用启动时配置。删除默认提供商或移除默认模型之前，必须先切换默认模型。

选择已保存提供商后，可以编辑模型列表或删除提供商。密钥不回显；同一地址留空保留旧密钥，变更地址时需重新填写密钥，也可勾选“清除已保存密钥”。切换提供商时会提示未保存修改。

“连接测试模型”可以选择该提供商任一已保存模型，点击“测试已保存配置”发送短消息，可能产生少量费用；测试不改变全局默认模型，未保存修改时不能测试。

点击“新建对话”发送消息，可以停止生成。失败、取消或中断后，点击“以新任务重试”会创建新任务；刷新页面或重连不会重新提交。当前同时只运行一个任务，取消后的清理期间也不能启动新任务。

兼容接口不代表所有服务均可直接使用，请使用提供商实际支持的模型并测试连接。

## 3. 助手设置与模板

进入“设置 → 助手设置”，按分类编辑名称、Emoji、角色、性格、用户资料、时区、行为规则和工具约定。首次引导可跳过。规则可排序、禁用和删除；总配置最多 12,000 字符，规则最多 30 条，每条最多 2,000 字符。

保存后从下一次提交消息生效，已有会话的新一轮也适用。运行中或等待批准的任务继续使用创建时配置；历史消息正文不变，聊天标签显示当前名称。

“预览上下文”展示配置、运行信息和记忆，不包含会话历史，不调用模型或保存草稿。预算按字符展示，不是精确 token 数；性格 Markdown 使用安全渲染。

展开“助手模板”，可选择日常、开发或写作模板，预览差异后应用到草稿，再保存生效。模板保留身份名称和用户资料。

设置只保存当前值，版本号用于并发校验。不同页面同时保存发生冲突时，先保留需要的草稿，再重新加载当前设置。不提供配置备份、导入导出、历史列表或版本恢复。

## 4. 会话补充规则

选择对话后点击右上角会话菜单，进入“会话详情与规则”，展开“会话补充规则”，输入最多 4,000 字符并保存，仅影响此对话的新任务。清空后保存可停用；也可预览其与当前全局配置组合后的内容。

表达偏好按本次明确要求、会话补充、全局默认理解。任何文字都不能改变服务端工具权限或代替覆盖批准。源码或上传文件中的协作说明不会自动成为产品规则。

会话规则也有并发保存校验。切换、新建或删除对话前若有未保存草稿会提示；取消新建不会创建多余会话。

## 5. 文件与授权

可以让助手列出目录、读取 UTF-8 文本、搜索和写入文本。路径以授权目录为根，根目录用 `.`，子路径用正斜线，父目录需已存在。当前没有创建目录、删除文件或浏览器自动化工具。

新文件直接创建；覆盖文件时，核对参数后点击“允许本次操作”或“拒绝”。批准绑定具体参数和文件内容，等待期间文件变化会使原批准失效。越界路径、符号链接、目录联接和多硬链接文件会被拒绝。

进入“文件”页可通过面包屑浏览目录、上传、下载或复制相对路径。单文件最多 64 KiB，总配额 20 MiB、500 文件；上传不覆盖同名文件。任务运行或清理期间不能上传。

## 6. 记忆、运行记录与系统日志

进入“记忆与技能 → 长期记忆”手动添加、编辑或删除内容，并设置优先级。记忆只用于后续任务，不会从聊天自动保存；删除不会追溯修改已运行任务的上下文。不要存入凭据。

进入“运行记录”，可按每页 50 条加载任务，查看工具参数、结果、耗时和服务上报用量。未上报用量不估算。状态 `succeeded`、`failed`、`cancelled`、`interrupted` 分别为成功、失败、取消、中断。

服务重启将未完成任务标为中断，不自动重复写文件或运行命令。

进入“系统日志”可查看服务生命周期、定时调度、消息渠道、连接测试、任务异常和敏感写入/命令操作的脱敏活动。页面默认实时更新，可暂停页面插入后集中查看新日志，也可按级别和来源筛选、分页加载历史。日志默认保留 7 天，可设置 1–30 天；缩短天数会立即清理旧记录，每用户最多保留 20,000 条。这里不展示聊天正文、密钥、文件内容或完整工具参数；更详细的异常堆栈在启动服务的终端标准输出中查看。

选择对话后从右上角菜单进入“会话详情与规则”，展开“会话摘要与上下文”可手动生成、清除或启用默认关闭的自动摘要。原始消息保留，摘要生成会调用模型。记忆搜索位于“长期记忆”，历史关键词搜索位于“运行记录”；历史默认全部会话，可选择当前已打开的会话并查看工具证据。详细预算、继续生成和删除语义见 [摘要与检索说明](CONTEXT_MEMORY.md)。

## 7. 联网搜索

进入“设置 → 联网搜索”，选择 Tavily，填写“搜索 API Key”，勾选“启用联网搜索”并保存。点击“测试联网连接”会使用已保存密钥查询一次，可能消耗服务额度。配置保存立即影响新任务，无需修改 `.env` 或重启。

“允许读取网页正文”控制原文提取；“允许定时任务联网”默认关闭，需要单独勾选保存。启用后可在聊天中要求搜索资料或总结公开网址，调用过程与来源复用聊天工具记录。密钥不回显，留空保留；勾选清除后保存会同时关闭联网。详细参数、权限变更语义与当前验证限制见 [联网搜索说明](WEB_SEARCH.md)。

## 8. 技能自动匹配

进入“记忆与技能 → 技能管理”，点击“新增技能”，填写名称、适用描述、关键词和 Markdown 步骤，可以添加参考文档；保存并启用后，直接在聊天中提出任务，无需每次选择技能。助手先查看目录，必要时检索正文，再读取选中技能。任务会显示本次加载的名称、版本与文档。

描述应明确使用场景；“搜索技能候选”仅测试已保存内容的关键词匹配，不调用模型。停用或删除会阻止后续读取，已经加载的运行内容需要取消任务才会停止使用。没有外部技能包安装或脚本执行。详见 [技能说明](SKILLS.md)。

## 9. 常见问题与限制

展开“定时任务”可创建固定站内提醒或只读 AI 计划，规则只用五段 Cron，按服务器时区执行；保存前可预览未来时间。关闭网页后仍会调度，服务停止或电脑休眠错过的触发不补跑。AI 结果保存为独立会话，可按计划设置投递到已绑定的 QQ 或微信。操作与示例见 [定时任务说明](SCHEDULES.md)。

QQ 与微信机器人可在网页“消息渠道 · QQ / 微信”配置。详细步骤、本人身份绑定、取消及平台使用限制见 [渠道接入说明](CHANNELS.md)。无需安装 OpenClaw 或修改全局配置。渠道凭据同样保存在数据库中，数据库不能纳入 Git 或助手授权工作目录。

| 现象 | 检查方式 |
| --- | --- |
| 登录或写请求返回来源错误 | 使用与 `APP_ORIGIN` 完全一致的地址，不混用 localhost 与 127.0.0.1；脚本请求也需提供 Origin |
| 提示已有实例 | 同一数据库只允许一个进程；检查是否重复启动，不删除运行中的锁文件 |
| 模型连接或工具调用失败 | 核对地址前缀、模型和密钥；服务需支持当前流式与工具调用协议 |
| 保存提示配置冲突 | 另一页面已更新配置；保留草稿后重新加载并合并 |
| `npm start` 后没有前端页面 | 默认只启动构建后的 API；先执行 `npm run build`，设置 `SERVE_WEB=true` 和对应 `APP_ORIGIN`，或本机继续使用 `npm run dev` |

前端采用独立页面与响应式布局。发布镜像不包含命令执行服务，请保留执行服务配置为空。

## 前端导航与交互

登录后默认进入对话；桌面左侧导航可收起，手机通过顶部菜单切换页面。会话标题支持服务端搜索及每页 50 条的“加载更多会话”。会话地址位于 `#/chat/会话ID`，刷新和浏览器前进后退可恢复对应会话。

消息框位于聊天底部，Enter 发送、Shift+Enter 换行；中文输入法组合输入不触发发送。向上阅读时不自动跳到底部，可点“回到最新”；加载更早消息保持阅读位置。消息与代码块均可复制。消息草稿仅在当前页面进程内按会话保留，切换功能页不会丢失；刷新、关闭或退出会清除草稿并提示。密钥不保存到浏览器存储。

顶部显示正在执行或等待确认的任务，点击可回到相关会话；任务在服务器继续执行，离开聊天页面不会重发。工具过程和实际加载技能位于“执行过程”折叠区，待授权操作单独持续展示。任务记录使用实际模型，顶部全局默认模型用于下一次任务。

“记忆与技能”包含独立的长期记忆和技能管理入口；技能点“新增技能”或“编辑技能”进入编辑区，保存后可返回列表试查。“运行记录”支持状态筛选、真实分页和任务详情；关键词搜索匹配已结束任务的输入及工具结果，最多 10 条，截断时明确提示。“系统日志”与运行记录分开，前者面向服务和后台活动，后者保留任务、模型及工具详情。

“定时任务”分为计划列表与“执行记录与提醒”；新建、编辑在抽屉完成，Cron 快捷按钮只填入五段表达式，预览由服务器计算。顶部“提醒”入口进入执行历史，未读数字仅统计固定站内提醒；发送状态与任务执行状态分开展示。
